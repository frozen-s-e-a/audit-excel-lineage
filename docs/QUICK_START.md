# Windows 基础测试版 0.4

## 下载后运行（无需安装 .NET 或 Excel）

1. 登录有权访问仓库的 GitHub 账号，打开仓库的 Actions。
2. 打开最新成功的 `Windows test build` 运行。
3. 在页面底部 Artifacts 下载 `AuditLineage-Windows-x64`。
4. 将 ZIP 完整解压到本地文件夹，双击 `AuditLineage.exe`。不要只复制 exe，也不要在压缩包里运行。
5. 添加 .xlsx/.xlsm，选择输出目录，点击“开始处理并另存”。

目标：Windows 11 x64。下载包自带 .NET 运行时；首次版本未做代码签名。不需要联网处理文件，程序不调用外部模型、不启动 Excel、不执行宏、不刷新外链。GitHub 构建产物保留 30 天，过期后可在 Actions 选择 Run workflow 重新生成。

## 这版的处理规则

| 内容 | 行为 |
| --- | --- |
| 工作表中 t 缺省或为 n 且非空的数值 | 替换为 0，包括负数、小数、百分比、数值型日期和数值型编号 |
| 具有 f 节点的公式单元格的数值缓存 | 删除对应 v 节点，不修改 f 文本及属性 |
| 共享公式、数组公式表达式 | 保留文本和分组/范围属性，不展开、不解析、不脱敏 |
| 数组结果区域中没有 f 节点的数值 | 与普通数值一样替换为 0，不判断计算归属 |
| 文本、“数字文本”、布尔、错误、空单元格 | 保留 |
| t=d 的 ISO 日期文本 | 保留；本版按存储数值类型处理，不进行日期语义识别 |
| 表名、文件名、样式、公式内字面量 | 保留；XML 排版和前缀形式可能重写，但公式文字和属性含义不变 |
| 图表/透视表/外部链接缓存、嵌入文件、宏、元数据 | 保留，不属于工作表数值处理范围 |

输出名称增加 `.numeric-only.<随机标记>`，保留扩展名。原文件只读，不覆盖已有输出。取消时删除当前临时文件，保留之前已完成的输出。输出采用较快压缩，体积可能大于输入。磁盘需容纳源文件及新文件。

这不是完整匿名化：公式写死的金额、文本中的名称、附属对象中的数据仍可能存在。打开输出时 Excel 可能重新计算，硬编码公式可能再次显示数值，除以 0 等错误也可能出现；不保证原有勾稽结果。请先测试再决定用途，不能把“完成”理解成适合直接对外发送。

## 建议首次测试

下载包附带 `synthetic/synthetic-input.xlsx` 与 `synthetic-output.xlsx`，均由程序从零构造。先处理合成输入，检查普通数值归零、文本保留，并从 Excel 公式栏核对公式。已保存缓存的检查以文件 XML 为准，打开 Excel 后可能重算。合成测试结果不能代替你本地的 Excel/WPS 兼容性确认。

再测试自己的一个副本，核对多表、隐藏数据、输出打开情况、处理耗时和数值替换计数。反馈可只包含应用版本、文件格式/大小、耗时和固定错误提示，不需要上传业务值或原始公式。本版未承诺 50MB 或百万级公式的固定耗时。

## 从源码启动

安装 .NET 10 SDK，下载或克隆仓库后双击 `run-windows.cmd`。也可以在 PowerShell 执行：

```powershell
dotnet run --project src/AuditLineage.Desktop -c Release
```

生成自包含程序：双击 `build-windows.cmd`。生成目录为 `artifacts/windows-x64`。测试核心可在支持 .NET 10 的系统运行：

```powershell
dotnet run --project tests/AuditLineage.Tests -c Release
```

## 实现与限制

核心使用 .NET 自带 ZipArchive、XmlReader/XmlWriter，逐个 ZIP 部件和单元格处理。首版无需 SQLite、第三方公式解析器或 Open XML SDK；这些仍属于后续溯源产品的候选模块。共享字符串不整体加载，不执行公式，不创建整表 DOM。单个单元格会临时加载，超大单元格仍可能增加内存。

不支持 .xls/.xlsb、加密工作簿、带 OOXML 包数字签名的文件。包上限为 10 万成员、声明解压总量 8GiB，超出则失败，不静默截断。不是所有 Excel/WPS 特性都经过实测。失败时继续下一文件，并显示固定错误类别；不写入包含实际数据的诊断日志。
