# 数值处理规则 · 基础测试版 0.4

2026-09-10。用户已明确将首版范围改为“不处理公式，只处理数值”。本规范替代 0.3 方案对当前程序的公式参数化和安全逻辑包要求；后续溯源功能另行开发。

## 当前规则

- 只读 .xlsx/.xlsm，输出独立工作簿，保留原扩展名，不覆盖输入或已有输出。
- 所有工作表参与，包括隐藏表及隐藏行列。单元格 t 缺省或为 n，且 v 非空时按存储数值类型处理。
- 非公式数值替换为 0；具有 f 节点的数值缓存删除 v。共享公式和数组公式的 f 文字与属性保留，不解析、不展开、不替换任何公式字面量。
- 没有 f 的数组结果成员按普通数值置零。无需判断公式归属即可执行本规则。
- 数值型日期、百分比、数值型编号均置零；t=d 的 ISO 日期、数字文本、普通文本、布尔、错误及空值保留。不根据显示格式猜测业务含义。
- 公式内部数字、文本、工作表名、文件名及其他 ZIP 部件保留。图表、透视表、外部链接、数据模型、嵌入对象、宏和元数据均不做脱敏。
- 原始数据允许保存在使用者本地；禁止将实际底稿、运行输出、临时文件或实际内容日志提交到 GitHub/在线 CI。

## 输出含义

完成仅表示规则执行结束，不代表完整脱敏或可对外分享。输出仍可能包含真实名称、公式硬编码金额和附属缓存。Excel/WPS 打开后可能重算，公式硬编码值可能重新显示，数值归零可能导致计算错误。程序不重算、不更改计算模式、不执行宏、不刷新外链。

## 实现边界

原工作表 XML 会重新序列化，排版、前缀或空元素写法可能不同；公式文字及属性语义须保持一致。逐个单元格读取，不将整张工作表加载到内存。输出在同目录临时文件写完后再发布，异常或取消清理当前临时文件，之前完成的文件保留。

包数字签名会因改写失效，因此本版拒绝带 _xmlsignatures 的包。加密文件、旧格式和超出预算的包失败退出，不静默省略。

## 验证

自动化测试仅使用从零构造的工作簿，核对公式及其属性、数值和缓存、其他部件、原文件哈希、隐藏结构、失败清理及覆盖保护。正式 Excel/WPS 打开兼容性和 50MB 性能仍需本地验收。使用步骤见 [运行说明](QUICK_START.md)。
