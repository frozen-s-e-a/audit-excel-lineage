# Excel 存储分类与布局适配

版本：0.3 · 2026-09-10 · 待实现设计

## 1. 存储结构

.xlsx/.xlsm 的工作表 XML 在同一单元格记录中分别存放公式和保存值，并非独立的公式数据库与数值数据库。读取器必须依据部件关系定位，不能凭固定文件路径编号建立表关系。.xls/.xlsb 使用独立适配器，不能套用 XML 节点规则。

| OOXML 信息 | 本地解释 | 注意事项 |
| --- | --- | --- |
| c/@r | 单元格地址 | 与工作簿和工作表标识组合定位 |
| c/f 及其属性 | 公式文本、类型、分组、范围 | XML 公式通常没有开头等号；存在节点不等于存在完整公式文本 |
| c/v | 普通值、公式缓存或共享字符串索引 | 结合公式归属与 c/@t 判断，不统一视为业务数值 |
| c/@t、c/is | 值类型和内嵌文本 | 类型属性可缺失；文本形似公式不代表公式 |
| sharedStrings | 共享文本 | 流式索引和有界缓存；索引数字不是金额 |
| c/@s、styles、workbookPr/@date1904 | 格式与日期解释依据 | 日期常为数值，也存在日期类型编码；格式只能提供语义证据 |

缓存可能缺失、为空或过期；存在 v 节点不证明结果有效。区分空单元格、空字符串、数值零、布尔值、错误值及无缓存。不重算原工作簿，不刷新外链。

参考：[微软公式说明](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/working-with-formulas)、[单元格值读取](https://learn.microsoft.com/zh-cn/office/open-xml/spreadsheet/how-to-retrieve-the-values-of-cells-in-a-spreadsheet)、[共享公式及区域属性](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.cellformula)。

## 2. 三个独立分类维度

| 维度 | 本地分类举例 | 依据 |
| --- | --- | --- |
| 内容来源 | 常量、普通公式、共享主公式/成员、数组锚点/结果成员、未知计算归属 | 公式节点及组/区域元数据 |
| 存储值类型 | 数字、文本、布尔、错误、日期编码、空/未知 | 类型标记、共享文本解码与值节点 |
| 业务含义 | 金额、数量、日期、账户标识、表头、阈值、未知 | 格式、标签、区域、项目规则及本地确认 |

同一单元格可同时属于“公式来源、数值缓存、市值字段”。保留各分类的证据和状态；技术分类不自动决定敏感性或公开资格。日期解释同时保留原始存储值及日期系统，避免丢失依据；编号不擅自转数字或删除前导零。

## 3. 处理顺序

1. 只读扫描工作簿关系、类型、公式属性、格式与必要结构，原始信息分批写入私有记录。
2. 建立共享公式主成员关系；按相对位移和绝对引用标志恢复成员表达式，缺主公式时记录未知。
3. 识别数组/溢出锚点与可确定的结果范围；缺少可靠范围时保持未知，不推算真实结果，不把区域成员归为手工输入。
4. 解码值类型并关联计算归属；只对已排除计算归属的值记录输入节点。外部生成或人工粘贴来源仍可能未知。
5. 对支持表达式生成语法树和潜在依赖；未知函数、动态范围和不支持语法保留断点。
6. 在业务区域内识别标签与单位，生成本地候选含义，再执行参数化和安全导出。

公式中的字面量另行按语法位置分类。禁止因为公式属于计算逻辑就原样输出，也禁止将所有数字一律删除。

## 4. 适配不同布局

通用提取器不依赖特定表名、固定列号或第一行表头。业务区域识别结合合并区域、相邻标签、空白分隔、公式分布与格式提示，允许一张表有多个区域、横向期间和多层表头。格式和邻近关系仅是候选证据。

使用“通用结构读取 + 可配置语义规则 + 本地复核”。规则具有版本与适用范围，可记录项目、工作表或业务区域，但不能将某个参考底稿的布局写死为全局要求。字段重命名、列移动及缺标题时继续保留技术依赖；语义歧义使用匿名字段和待确认状态，不强行匹配。

## 5. 私有存储与安全映射

本地模型可保存原始值、缓存、原始公式、共享组、结果范围、类型、样式依据、原始名称、来源版本、语义证据及匿名映射。原文件只读，运行数据位于仓库外，普通日志不倾倒原始记录。

存储模型与对外模型分别定义，导出器只接受经过检查的安全 DTO。对外仅包含匿名位置、经审核标签、参数化表达式及解析状态；值、缓存、原始文本、名称映射和内部诊断留本地。允许本地保存不改变 values_included=false。

## 6. 验收条件

- 共享字符串索引不误当金额，字符串形似公式不误作公式，公式无缓存不被漏读。
- 数字、日期系统、布尔、错误、零、空字符串和空单元格分别验证。
- 共享公式恢复正确；数组区域成员不误归输入，无法确定的计算归属明确报告。
- 多种合成布局下，公式依赖正确且语义歧义不被隐藏；不以单一底稿代表全部兼容性。
- 私有持久化内容仅本地可查；最终序列化产物没有合成敏感标记、原始值或缓存泄漏。
- 百万级样本采用有界队列、批量事务及区域索引；不将所有单元格对象装入内存。

参考文件仅用于发现结构场景。本仓库不保存其实际值、原始公式、原始名称、文件标识或精确结构指纹。样例与自动化测试从零构造。
