# 可执行开发任务

状态：以下任务均未开始。方案与样例的交付不等于应用功能已完成。

## 阶段一：验证解析与隐私边界

先确认实际格式、目标 Windows 版本和电脑配置，再用完全虚构样本确认路线；完成验证后估工期。

| 任务 | 实现内容 | 完成条件 |
| --- | --- | --- |
| P01 | 建立 C#/.NET 10 解决方案、依赖锁和 CLI；确认格式与机器基线；读取层独立于 UI | Windows 构建通过，CLI 显示版本，定义 IWorkbookReader 与安全 DTO；锁定 SDK/NuGet |
| P02 | 创建合成金标准样例集 | 覆盖普通/共享公式、数组结果归属、多布局、值类型、日期系统、隐藏表、跨文件、重名、数字与文本字面量，不含真实底稿 |
| P03 | 调研真实模板特征的本地盘点方式 | 输出匿名格式/函数类别/盲区统计；不把原公式或名称发到外部 |
| P04 | 实现安全记录与导出器边界 | 原始记录不能被导出 API 接受；未知字段、敏感标记和未支持公式旁路有拒绝用例 |

## 阶段二：CLI 闭环

阶段一发现的语法问题可调整范围，必须更新支持矩阵；不预设未经验证的工期。

| 任务 | 实现内容 | 完成条件 |
| --- | --- | --- |
| P05 | 批量只读扫描、文件事务与恢复点 | 中文路径、单文件失败、取消和输入变化有明确结果 |
| P06 | C# 分词器与支持子集表达式解析器 | 运算优先级、函数参数、静态 A1 引用通过金标准；不支持项有固定状态 |
| P07 | OOXML 类型解码、关系、名称作用域、共享公式及数组结果归属 | 公式来源与值类型分离，跨文件歧义不猜选，共享公式可核对；数组结果不误作输入，未知范围明确记录 |
| P08 | SQLite 私有原始记录、依赖索引与循环检测 | 整列引用紧凑存储，可追溯上下游且不无限递归 |
| P09 | 多布局业务区域、三维分类、别名、语义白名单与参数化 | 整批一致；业务值、缓存、路径和敏感文本均不进入导出 |
| P10 | 公式归并与例外 | 混合引用、错行和硬编码变化不被合并隐藏 |
| P11 | JSON 导出、覆盖率和缺失项 | 支持 strict 阻止发布与 reviewed 子集导出，规则和 scope 可追溯 |

阶段二交付：可实际处理支持范围内文件的本地 CLI，以及从合成输入得到的验证报告。先达到该阶段，再接桌面界面。

## 阶段三：Windows 界面与交付

CLI 通过准确性和隐私验收后开始；具体工期按界面原型与本地性能基线确定。

| 任务 | 实现内容 | 完成条件 |
| --- | --- | --- |
| P12 | WPF + MVVM 项目/扫描/结果/复核/导出页面 | 后台任务可取消，UI 无长时间阻塞 |
| P13 | 上下游树与局部依赖图 | 节点数有上限，完整路径和原始内容只在本地上下文显示 |
| P14 | 实际导出预览与错误定位 | 用户能逐项查看将被发送的文件内容，未知项不会被隐藏 |
| P15 | 50MB 与百万级公式本地压测、.NET 自包含目录发布 | 记录阶段耗时、峰值私有内存与覆盖率；无预装 .NET/Excel 的 Windows 基线机器运行；中文路径通过 |
| P16 | 使用说明与版本发布 | 说明支持矩阵、已知缺陷、隐私边界、构建方式；没有“已支持所有 Excel”的表述 |

## 后续版本候选

按用户实际底稿的覆盖收益排序：结构化引用、数组/溢出、公式型名称、旧格式、Power Query/透视配置、按规则执行的本地数值检查。先建立针对性样例，再承诺支持。

## 发布门槛

解析准确性、隐私漏出与 Windows 交付验证是三个独立门槛；任何一项缺失都应标记对应限制。通过 schema 校验不等于通过隐私验证，成功启动界面也不等于完成批量提取。
